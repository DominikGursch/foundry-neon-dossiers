The existing MIT license is preserved. Its copyright/license notice must
accompany substantial copies of the software; MIT does not require an in-app
credit field. Artwork attribution follows CC BY 4.0. Both licenses allow
commercial reuse of the material they cover. Publisher fan-content terms are
separate restrictions on publisher IP, not extra restrictions on this MIT code
or the original CC BY artwork.

The four SVG assets were drawn directly as original geometric SVG code for this
project. They use generic shapes, system sans-serif fonts and an independent
teal/amber palette. No external fonts, CDN, art packs, game book illustrations,
publisher logos, DLC files or assets from other map modules are bundled.
The three starter place descriptions are new fictional text, not rulebook
extracts or statblocks.

This is an independently authored implementation from abstract feature ideas:
maps, places, categories, dossiers and permissioned sharing. No source, text,
UI layout or assets were retrieved from the earlier third-party map project
for implementation. This is **not a claim of strict clean-room development**:
the coordinating session had previously seen that project's code.
