# Image and map sources

Research context: 5 November 2026. This is a practical rights checklist, not
legal advice. Check the current terms and the specific file before each use.

## Included now: original assets

The default Harbor Grid district map and three dossier illustrations were
created for this module. They depict an invented district, not Night City.
See `LICENSES/ASSETS.md` for the precise CC BY 4.0 scope and attribution.
This is the only artwork shipped in v0.1.0.

## Official free DLC: links, not redistributed assets

The official download page is:
https://rtalsoriangames.com/downloadable-content/

It lists resources such as Night City Atlas, Karaoke Night maps and 100 Logos.
The Night City Atlas reference is:
https://rtalsoriangames.com/wp-content/uploads/2025/01/RTG-CPR-DLC-NightCityAtlasv1.01.pdf

Free download does **not** establish permission to redistribute, sublicense,
bundle, trace, extract or hotlink its images in this project. The module does
none of those things and never downloads DLC automatically. This project has
not obtained a redistribution license for those files.

If you separately obtain publisher maps and have permission for your intended
use, put the permitted image file in your Foundry user-data directory and use
the local file picker. Do not upload it to this repository. A local Foundry
server can still transmit image files to connecting clients; private hosting
is not a blanket copyright exemption. Check the relevant permissions for that
use too. Do not assume every DLC has the same terms.

Publisher policy:
https://rtalsoriangames.com/homebrew-content-policy/

## Other possible sources

Your own drawings and commissioned art with explicit distribution rights are
the simplest options. Public-domain/CC0 or CC BY sources may be suitable only
after verifying the individual file's provenance, license and any separate
trademark/privacy restrictions. No external catalog has been imported or
certified by this release. Keep a per-file record of author, original URL,
license/version, download date and modifications before adding third-party art.

The MIT license cannot relicense someone else's image. Do not add a commercial
art pack just because you own a copy. Do not reproduce protected geography or
trade dress by tracing a proprietary map.
